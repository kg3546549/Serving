# STACK//BREACH 한눈에 보는 게임 요약

> 이 문서는 현재 구현된 아키텍처 디펜스 프로토타입을 설명한다.

## 한 줄 설명

파스텔 격자 보드에 클라우드 장비를 배치하고 트래픽 길을 직접 그려 서버 폭주를 막는 시스템 아키텍처 디펜스 게임이다.

## 현재 플레이 목표

단일 앱 서버로 작은 웨이브를 처리한 뒤, 더 큰 웨이브에서 발생하는 병목을 관찰한다. 실패 후 로드밸런서와 두 번째 서버를 배치하고 올바른 분산 경로를 완성해 서비스를 안정화한다.

## 실제 플레이 순서

1. 입구에서 앱 서버 A로 선을 그린다.
2. 앱 서버 A에서 데이터베이스로 선을 그린다.
3. 20개 요청 웨이브를 시작한다.
4. 50개 요청 웨이브에서 Queue 포화와 실패를 확인한다.
5. 해금된 로드밸런서와 앱 서버 B를 원하는 빈 격자 칸에 배치한다.
6. 입구, 로드밸런서, 두 서버, 데이터베이스를 분산 구조로 연결한다.
7. 50개 요청을 두 서버로 나눠 처리한다.

## 핵심 조작

- 장비 카드 드래그 → 빈 격자 칸에 배치
- 장비 카드 선택 → 강조된 격자 칸 클릭
- 장비에서 다른 장비까지 드래그 → 경로 연결
- 같은 연결 다시 그리기 → 해당 경로 제거
- `그린 길 지우기` → 전체 연결 초기화
- `웨이브 출격` → 현재 구조로 시뮬레이션 시작

## 클리어 경로

첫 웨이브:

```text
트래픽 입구 ─ 앱 서버 A ─ 데이터베이스
```

최종 웨이브:

```text
트래픽 입구
  └─ 로드밸런서
      ├─ 앱 서버 A ─ 데이터베이스
      └─ 앱 서버 B ─ 데이터베이스
```

서버 B만 추가하거나 로드밸런서까지의 선만 그으면 분산 처리가 동작하지 않는다.

## 화면에서 확인하는 정보

- 요청 처리 진행률
- 완료 요청 수
- 보유 코인
- 서버별 Queue 길이
- 서버 부하 압력 링과 표정
- 성공률
- 평균 지연 시간
- 최대 Queue
- Drop·Timeout
- 획득 코인과 병목 원인

## 디자인 방향

- 네온 사이버 화면이 아닌 밝은 파스텔 게임 월드
- 풍선 타워 디펜스처럼 읽기 쉬운 둥근 실루엣
- 작은 장비 캐릭터와 단순한 표정
- 크림, 민트, 라벤더, 하늘색, 노란색 중심
- 클라우드 서비스 콘솔에서 착안한 단순한 자체 벡터 아이콘
- 기능 대시보드보다 배치, 이동, 실패, 성공이 보이는 게임 화면

## 현재 구현 범위

- 하나의 스테이지
- 두 개 웨이브
- 로드밸런서와 앱 서버 B 구매·배치
- Round Robin 분산
- Tick 기반 서버 처리와 Queue
- Phaser 트래픽 연출
- React HUD와 결과 화면
- 단위 테스트 13개

상점, 업그레이드, 합성, 다양한 장비, 캠페인 10개는 향후 기획이며 현재 구현에는 포함되지 않는다.
