## 작업 배경

기존 우측 상점은 웨이브 정보, 보유 장비, LINK 용량, 상품 목록을 한 세로 패널에 모두 표시했다. 장비를 구매할수록 보유 장비 영역이 상점 공간을 차지해 실제 구매 가능한 상품이 하단 스크롤에 묻히고, 구매와 배치 영역의 역할도 시각적으로 구분되지 않았다.

## 요구사항

- 보유 장비를 서비스 개시 Progress Bar 아래에 배치
- 보유 장비를 더 쉽게 확인하고 배치
- 우측 상점의 상품 가독성 개선
- 기존 클릭·드래그 배치 동작 유지
- 구매 전 빈 상태와 구매 후 배치 상태를 명확하게 표현

## 주요 설계 결정

### 상점과 Inventory 역할 분리

우측 `BuildDock`은 구매와 확장 기능에 집중한다.

- 현재 웨이브
- 요청 처리 순서
- LINK CAPACITY
- 장비와 DB 업그레이드 상품
- 간선 초기화

보유 장비는 별도 `InventoryDock`으로 분리해 서비스 개시 Progress Bar 바로 아래에 배치한다.

### 가로형 Inventory Dock

하단 공간은 세로 공간보다 가로 공간이 넓으므로 장비 카드를 수평으로 정렬한다.

- 왼쪽: 보유 장비 제목과 배치 개수
- 오른쪽: 가로 장비 카드 목록
- 빈 상태: 상점 구매 안내
- 구매 상태: `READY`
- 배치 상태: `ONLINE`

장비가 늘어나면 가로 스크롤을 사용하며, Stage 1의 최대 네 장비는 일반 화면에서 한 줄로 확인할 수 있다.

### 컴포넌트 분리

기존 `BuildDock.tsx`에 포함되어 있던 Inventory 카드와 드래그 처리 로직을 `InventoryDock.tsx`로 이동했다. 상점과 Inventory가 공유하는 장비 아이콘과 표시 이름은 각각 별도 파일로 분리했다.

## 변경 내용

### UI 배치

- Progress Bar와 Inventory Dock을 `bottom-operations` 영역으로 묶음
- Progress Bar를 첫 줄, Inventory Dock을 둘째 줄에 배치
- Phaser 월드 하단 여백을 늘려 UI와 겹치지 않게 조정
- 우측 상점에서 보유 장비 섹션 제거
- 상점 상품 카드 높이와 간격을 줄여 더 많은 상품을 한 화면에 표시

### Inventory 카드

- 장비 아이콘, 분류, 이름, 배치 안내 표시
- `READY`와 `ONLINE` 상태 Badge 추가
- 전체 보유 수와 배치 수 표시
- 기존 카드 클릭 배치 유지
- 기존 카드 드래그 배치 유지
- 웨이브 실행 중 비활성화 유지

### 코드 구조

- `InventoryDock.tsx`: 보유 장비 목록과 드래그 처리
- `DeviceIcon.tsx`: 상점과 Inventory가 공유하는 장비 SVG
- `devicePresentation.ts`: 장비 이름과 분류 메타데이터
- `BuildDock.tsx`: 구매 전용 패널로 축소
