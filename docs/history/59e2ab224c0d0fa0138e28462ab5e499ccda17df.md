## 작업 배경

보드가 고정 배율과 고정 위치로만 표시되어 보드 확장 후 전체 구조를 보거나 특정 서버와 링크를 자세히 확인하기 어려웠다. 카메라 기능을 추가하되 기존 장비 이동, 링크 연결, Inventory 카드 드래그 배치와 충돌하지 않아야 했다.

## 요구사항

- 보드 자유 확대·축소
- 보드 화면 자유 이동
- 기존 장비와 링크 조작 유지
- 확대·이동된 상태에서도 정확한 장비 배치
- 조작법을 화면과 도움말에 표시

## 주요 설계 결정

### 카메라 조작

- 마우스 휠: `0.6배~2배` 확대·축소
- 확대 기준점: 현재 마우스 커서 위치
- 빈 보드 좌클릭 드래그: 화면 이동
- 휠 버튼 드래그: 화면 이동
- Space+좌클릭 드래그: 화면 이동
- `R`: 배율과 화면 위치 초기화

### 기존 조작과 분리

장비 위에서 시작한 드래그는 기존 장비 이동 또는 링크 연결로 처리한다. 배치 모드에서는 격자 클릭을 장비 배치로 우선 처리하며 같은 포인터 입력이 카메라 이동으로 이어지지 않게 억제한다.

### 카메라 좌표 보정

Inventory 카드는 React DOM에서 Phaser 캔버스로 드래그된다. 카메라가 확대·이동된 상태에서는 캔버스 좌표를 카메라 월드 좌표로 역변환한 뒤 격자 위치를 계산한다.
