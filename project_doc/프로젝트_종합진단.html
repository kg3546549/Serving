2. Mini Metro식 그래프 퍼즐의 진단
Graph System
✕ 현재 구현의 근본적 문제점
  • 정적인 배선 환경: 서비스 개시(시뮬레이션 실행) 중에는 마우스 드래그를 통한 실시간 선 연결 및 분리가 원천 차단됨.
  • 긴급점검의 리스크: 선을 고치기 위해서는 시뮬레이션을 도중에 멈추는 '긴급 점검'을 해야 해 실시간 임기응변의 재미가 결여됨.
  • 고정된 입/출구: Ingress와 Egress가 고정되어 매 웨이브마다 새로운 역이 생겨 동적으로 노선을 바꾸는 Mini Metro의 긴장감이 없음.
✓ 지향해야 할 개선 전략
  • 실시간 핫플러깅(Hot-Plugging): 시뮬레이션 동작 중에도 링크를 끊고 새로 연결하는 기능 제공. 단, 트래픽 유입 중 끊길 시 데이터 손실(Drop) 패널티 부여.
  • 트래픽 우회(Dynamic Routing): 로드밸런서가 실시간 링크 끊김을 감지하여 동작 중인 다른 활성 서버로 유연하게 경로를 변경하는 로직 고도화.
  • 무작위 가설 이벤트: 웨이브 중 특정 시점에 임의의 위치에 서브 Ingress(새로운 트래픽 창구)가 개설되어 급박한 신규 배선을 유도.
3. Auto Chess + TFT 식 경제/합성의 진단
Economy & Merge
✕ 현재 구현의 근본적 문제점
  • 기기 배치와 패시브의 단절: 큐(SQS), 캐시(Redis), 보안(WAF) 장비는 보드에 배치되지 않고 인벤토리에 보관만 해야 패시브가 작동하므로, 공간 배치 퍼즐과의 결합도가 떨어짐.
  • 단순한 수치 버프식 증강: 합성 시 얻는 증강(Augment) 카드가 연출 변화 없이 '처리 속도 X배' 같은 단순 내부 계수 보정에 그쳐 체감이 약함.
  • 부족한 시너지(Synergy): 특정 제조사(예: AWS 계열, Apache 오픈소스 계열)나 역할군 시너지 배치가 부재하여 장비 선택이 단순화됨.
✓ 지향해야 할 개선 전략
  • 인라인 패시브 카드 배치: WAF, Redis 등도 보드 위의 서버나 DB 노드 슬롯에 모듈 형태로 드롭하여 장착할 수 있도록 장비 슬롯형 아키텍처 개편.
  • 증강 시각화 및 패킷 스킨: 증강 선택 시 기기의 스프라이트 외형이 빛나거나, 해당 기기를 거쳐 가는 패킷의 모양(예: 캐싱 패킷은 민트색 광점)이 고유하게 변화.
  • 인프라 벤더 시너지: 'AWS 올인원'(EC2 + RDS + ALB 배치 시 시너지), '오픈소스 스택'(Apache + DocumentDB) 등 시너지 조합 UI 설계.
4. Bloons TD 식 패킷 시퀀스의 진단
Defence Sequence
✕ 현재 구현의 근본적 문제점
  • 정적 일괄 연산(Batch) 방식: 시뮬레이션 버튼을 누르는 순간 메모리에서 60초 치 결과를 다 구한 뒤(Offline Simulation), Phaser는 이벤트를 단방향 플레이백(비디오 재생)만 함.
  • 실시간 개입 차단: 이로 인해 플레이어가 패킷이 흘러가는 도중 타워(서버)를 실시간 업그레이드하거나 Credits로 큐를 비워내는 긴급 조작이 불가능함.
  • 단방향 디바이스: 타워디펜스처럼 패킷을 공격/처리하는 투사체 및 다중 공격 속성이 부족하고, 일대일 큐 전달 방식으로만 묘사되어 시각적 역동성 부족.
✓ 지향해야 할 개선 전략
  • 이벤트 드리븐 실시간 시뮬레이션: Batch 방식에서 탈피하여, 매 Tick(100ms)마다 보드와 상태를 계산하고 즉시 렌더링에 반영하는 동적 스레드로 전환.
  • 실시간 경제 개입: 웨이브가 도는 중에도 몬스터(패킷)를 성공적으로 처리하여 획득하는 Credits를 사용해 실시간으로 서버 노드 성능을 즉시 업그레이드 가능하게 개조.
  • 시각적 스킬 연출: 서버가 과부하(Queue Full)일 때 수동으로 과부하 해소 펄스 스킬을 눌러 큐를 날려 보내는 액티브 액션 추가.
5. 핵심 리팩토링 아키텍처 로드맵
Refactoring Plan
1단계
실시간 스냅샷 시뮬레이터 전환 (Batch ➡️ Realtime Tick)
- `simulateTrafficWave`를 단발성 루프에서 실시간 프레임 스케줄러로 개조.
- 프론트 HUD 및 Phaser 마우스 리스너가 시뮬레이션 상태 계산 도중에도 실시간 개입하도록 상태 변경 핸들러 추가.
2단계
실시간 배선(Hot-Plug) 및 패킷 손실 시스템 구축
- 시뮬레이션 중 링크 단절 감지 시, 해당 노드 내부에 계류 중인 패킷은 즉시 공중 폭발(Drop) 처리.
- Ingress에서 끊어진 회선을 대체할 대체 경로 자동 우회 라우팅 테이블 실시간 계산기 탑재.
3단계
보드 인터랙션 확장 및 벤더 시너지 UI 통합
- 패시브 장비 장착용 슬롯 인터페이스 추가.
- 합성 시 생성되는 증강 효과의 시각 투사체 VFX(예: 캐시 히트 시 파란 아우라 이펙트 등) 추가로 비주얼 체감 강화.
