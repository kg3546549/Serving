# STACK//BREACH

트래픽 경로를 직접 설계하고 서버 병목을 해결하는 파스텔 아키텍처 디펜스 게임입니다.

현재 저장소에는 `Stage 3: 서버 한 대의 한계`를 처음부터 끝까지 플레이할 수 있는 수직 프로토타입이 구현되어 있습니다.

## 현재 플레이 방식

1. 9×4 격자 보드에서 장비를 우클릭 드래그해 트래픽 경로를 그립니다.
2. 첫 웨이브는 `트래픽 입구 → 앱 서버 A → 데이터베이스` 경로로 처리합니다.
3. 두 번째 웨이브에서 단일 서버의 Queue 포화와 요청 실패를 확인합니다.
4. 실패 후 해금되는 로드밸런서와 앱 서버 B를 빈 격자 칸에 직접 배치합니다.
5. 다음 분산 경로를 완성하고 두 번째 웨이브에 재도전합니다.

```text
트래픽 입구
  └─ 로드밸런서
      ├─ 앱 서버 A ─ 데이터베이스
      └─ 앱 서버 B ─ 데이터베이스
```

장비를 짧게 우클릭하면 상세정보가 열립니다. 우클릭 드래그 후 다른 장비에 놓으면 간선 연결, 빈 격자 칸에 놓으면 장비 이동으로 처리됩니다. 같은 장비 사이에 선을 다시 그리면 연결이 제거됩니다.

## 구현된 기능

- Phaser 3 기반 풀스크린 게임 보드
- 크림·민트·라벤더·하늘색 중심의 파스텔 디자인
- 작고 둥근 장비 캐릭터와 클라우드 서비스 계열 평면 아이콘
- 9열×4행 격자와 모든 활성 장비 자유 이동
- 카드 드래그 배치, 카드 선택 후 격자 클릭 배치
- 장비 우클릭 상세정보, 우클릭 드래그 이동·간선 연결
- 20초 준비 타이머와 하단 자동 웨이브 진행바
- 우측 대형 상점, 재화, 상점 레벨업, 할인 리롤
- 3·2·1 웨이브 카운트다운
- 요청 Spawn, Route, Queue, Processing, Complete, Drop·Timeout 연출
- 서버별 Queue 수치, 표정, 압력 링
- 성공률, 평균 지연, 최대 Queue, 획득 코인 결과
- 실패 후 장비 해금과 코인·설치 상태 유지
- Round Robin 방식의 2대 서버 분산 처리
- 효과음, 카메라 흔들림, 건설 효과, 클리어 콘페티

## 웨이브 규칙

| 웨이브 | 요청 | 목표 성공률 | 의도 |
|---|---:|---:|---|
| 첫 손님 | 20 | 95% | 단일 서버 경로와 기본 처리 확인 |
| 점심시간 폭주 | 50 | 90% | 단일 서버 병목 체험 후 수평 확장 |

시뮬레이션의 서버 한 대는 동시 요청 2개, Queue 7개를 처리합니다. 각 요청의 처리 시간은 620ms, 제한 시간은 3.6초입니다.

## 실행

요구 환경:

- Node.js 22 이상 권장
- npm 10 이상 권장

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`으로 접속합니다.

## 검증

```powershell
npm test
npm run build
```

## 코드 구조

```text
src/
├─ components/    React 메뉴, HUD, Build Dock, 도움말, 결과 화면
├─ game/          Phaser 보드, 장비, 경로, 트래픽 연출
├─ simulation/    프레임워크 비종속 Tick 기반 웨이브 판정
├─ store/         진행 상태, 코인, 배치 위치, 연결 정보
└─ audio/         Web Audio 효과음
```

React는 메뉴·HUD·진행 상태를 관리하고, Phaser는 게임 월드와 실시간 연출을 담당합니다. 웨이브 결과는 순수 TypeScript 시뮬레이션에서 먼저 계산한 뒤 Phaser가 이벤트를 시간순으로 재생합니다.
